# Dra. Nayanne Gomes · Odontopediatria Especializada & Calculadora Clínica

Calculadora de doses pediátricas, anestésicos locais e gerador de receituário odontopediátrico com visual neo-brutalista e lúdico.

## 🚀 Tecnologias

- **React 19**
- **Vite**
- **Tailwind CSS v4**
- **Lucide Icons**

## 💻 Como Rodar Localmente

1. Instale as dependências:
   ```bash
   npm install
   ```

2. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```

3. Abra [http://localhost:3000](http://localhost:3000) no seu navegador.

## 📦 Build para Produção

```bash
npm run build
```

## 🌐 Deploy no GitHub Pages

O deploy é realizado de forma automática pelo GitHub Actions configurado em `.github/workflows/deploy.yml`.
